§ 01 · LOGO SYSTEM
SECTION 01 — LOGO SYSTEM

C9D Consulting
logo variants.

Eight production lockups. Inter Tight 400 with -0.04em tracking. "C9D" in sodium amber; "Consulting" in warm ink. The Dossier system applied.

L-01 · PRIMARY HORIZONTAL
Primary horizontal wordmark — dark background
Default wordmark for dark-mode website headers, deck slide chrome, document headers, LinkedIn banner, email signatures. This is the mark to use unless a specific context calls for a different lockup.

L-02 · PRIMARY HORIZONTAL / LIGHT
Primary horizontal wordmark — light background
Same lockup for printed materials — letterheads, engagement letters, signed SOWs going to counsel, board memos in binder print. Color values shifted to the light-mode token map so contrast holds on cream and paper backgrounds.
c9d-consulting-wordmark-horizontal-light.svg
L-03 · STACKED
Stacked wordmark — square contexts, dark background
Square-format contexts: app icons at larger sizes, social media avatars (LinkedIn company logo, X/Twitter avatar), any placement where horizontal space is constrained but the mark needs to breathe. "Consulting" set at half the display size below "C9D".
c9d-consulting-wordmark-stacked-dark.svg
L-04 · STACKED / LIGHT
Stacked wordmark — light background
Same as L-03 for light-mode surfaces. Business card front, print collateral, signed-artifact watermarks.
c9d-consulting-wordmark-stacked-light.svg
L-05 · SINGLE-COLOR REVERSED
Single-color mono — bright ink on dark
Watermarks, transparent overlays, contexts where the amber accent would compete visually with surrounding content (e.g., appearing next to another amber element on a slide, or in a footer already carrying the primary lockup elsewhere on the page).
c9d-consulting-wordmark-mono-dark.svg
L-06 · SINGLE-COLOR MONO / LIGHT
Single-color mono — dark ink on light
Same as L-05 for light-mode print. Also used for reproductions where two-color printing is constrained (fax, photocopy, single-color letterhead engraving).
c9d-consulting-wordmark-mono-light.svg
L-07 · ENDORSED LOCKUP
Endorsed lockup with attribution — dark
For formal deliverables where the endorsed-house architecture must be visible in the mark itself: engagement letters, signed SOW covers, proposal covers to net-new prospects. The "A practice of Brandon Wilburn." attribution is locked and never modified.
c9d-consulting-endorsed-dark.svg
L-08 · ENDORSED LOCKUP / LIGHT
Endorsed lockup — light
Same as L-07 for printed formal deliverables.
c9d-consulting-endorsed-light.svg
L-09 · TAGLINE LOCKUP
Wordmark with primary tagline
Reserved use: campaign moments, tradeshow banners, LinkedIn hero images, deck opening slides. Uses Instrument Serif italic for the tagline (the accent face; never used elsewhere in body). Not for daily use — the primary horizontal lockup carries most contexts.
c9d-consulting-with-tagline-dark.svg
L-10 · MONOGRAM STAMP
Monogram — favicon and social avatar
The single exception to the "C9D Consulting full form" rule. Justified by the 16/32/48/180px space constraints of favicons, browser tabs, and small avatar contexts. Sodium amber block with reversed "C9D" — reads like a document classification stamp.
